# Skill: Summarize Blog Post

Use this skill when asked to summarize a post from kuyt.org.

## Inputs
- Post URL or slug.
- Desired summary length (short, medium, long).

## Process
1. Resolve the post to its markdown endpoint if available.
2. Read the full post before summarizing.
3. Preserve key arguments, examples, and conclusions.
4. Avoid adding facts not in the source.

## Output
- Plain-text summary.
- Optional bullet list of key takeaways.
- Optional quote block with one representative excerpt.
